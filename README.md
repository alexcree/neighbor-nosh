# Neighbor Nosh

Free neighbor-to-neighbor home-cooked meals platform.

Tagline: "Home-cooked meals from your neighbors."

This repo holds the static website draft: a single self-contained `index.html`
(exported from the Muse web artifact `neighbor-nosh`). Nothing on the site is
sent or saved — the post and application forms are previews.

Deploy: static hosting (Vercel). `index.html` at the repo root is the site.
